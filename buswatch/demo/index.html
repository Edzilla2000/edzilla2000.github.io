Bus Watch demo data

Static sample data for the Bus Watch Android app. Turning on Advanced → Use demo data on the sign-in screen makes the app read these files instead of signing in to a real MyBusStop account.

Everything here is invented. There is no real school, no real child, no real bus, and no connection to Southland Transportation. The moving bus in the app is computed from the current time against the stop list below, not recorded from anything.

  • routes.json — the demo account's routes
  • route-9001.json — morning run
  • route-9002.json — afternoon run

The app bundles a copy of these files, so it still works if this host is unreachable.
